# Demo video

A ~90s product demo built with [HyperFrames](https://hyperframes.heygen.com):
real screenshots from the live app (`assets/shots/`), a real [Kokoro
TTS](https://github.com/thewh1teagle/kokoro-onnx) voiceover (`assets/vo_*.wav`,
generated by `tts/speak.py` from `tts/script.json`), and captions synced from
a local Whisper word-level transcript of that same audio (`words/`). No
silent screenshot pans, no stock footage, no invented UI.

## Rebuilding

```bash
# one-time: create the venv used for TTS + transcription
cd tts && python3 -m venv .venv && .venv/bin/pip install kokoro-onnx soundfile mlx-whisper

# edit tts/script.json, then regenerate voiceover + transcripts
.venv/bin/python speak.py af_heart
.venv/bin/python transcribe.py

# rebuild index.html (timing, captions, scene layout) from the audio + words
cd .. && tts/.venv/bin/python build.py

# lint, look at frames, then render
npx hyperframes check --json
npx hyperframes snapshot --review
npm run render
```

`tts/.venv/` and `renders/` are gitignored (a large local virtualenv and a
regenerable build output, respectively) - see the repo root `.gitignore`.

`landing-capture/` is the raw output of `npx hyperframes capture
https://alreadycovered.vercel.app`, kept as the source of the real design
tokens and fonts used in `index.html`.
